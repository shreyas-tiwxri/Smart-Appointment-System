Layered System Architecture & Class Hierarchy

Designed strictly using Object-Oriented principles, separation of concerns, and clean encapsulation.

Presentation Layer

Console & UI Classes

PatientMenu.java Terminal UI for appointment request, status inquiry, and viewing medical records.
DoctorMenu.java Terminal UI for review queue, decision making, and recording consultations.
InputHelper.java Validated console parsing for integers, strings, and dd-MM-yyyy HH:mm dates.
Business Logic Layer

Service Controllers

AppointmentService.java Enforces past-date validation, creates initial PENDING requests, handles approval decisions.
ConsultationService.java Verifies APPROVED status, records diagnosis/Rx, and orchestrates automatic follow-up booking.
Domain Entities

Core Models & Enums

Appointment.java Stateful entity containing Patient, Doctor, LocalDateTime, AppointmentStatus, followUp flag.
Consultation.java Clinical record linking appointment, diagnosis text, prescription notes, next visit date.
AppointmentStatus.java Enum: PENDING, APPROVED, REJECTED.
Patient.java & Doctor.java Encapsulated entities for system actors with unique identifiers and contact/specialty details.
Data & Safety

Repository & Exceptions

InMemoryRepository.java Thread-safe collections storage using HashMap, LinkedHashMap, and ArrayList.
InvalidInputException.java Custom unchecked exception for past dates, empty strings, and malformed inputs.
InvalidStateException.java Custom exception preventing illegal transitions (e.g. deciding approved appointments).

Appointment State Machine & Automatic Follow-Up Flow

1
PENDING

Patient requests appointment with future date.

➔
2
APPROVED

Doctor accepts request (or sets to REJECTED).

➔
3
CONSULTATION

Doctor inputs clinical diagnosis and prescription.

➔
4
AUTO FOLLOW-UP

System automatically books new APPROVED appointment for next visit.

Encapsulation & Immutability

Java Collections Framework

Carefully chosen data structures: HashMap for $O(1)$ patient lookups, LinkedHashMap for chronological order, and ArrayList for query streams.

Modern Date & Time API

Utilizing java.time.LocalDateTime and DateTimeFormatter instead of legacy Date/Calendar for reliable temporal comparisons.

Type-Safe Enums
